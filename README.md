## About

I'm an independent developer focused on creating practical
desktop software, automation tools, and utilities for
everyday workflows.

My projects cover Windows applications, AI development
tools, video and image processing, and gaming peripherals.

**What I care about**

- **Usability** — Interfaces that feel clear and intuitive.
- **Performance** — Efficient software for real-world tasks.
- **Reliability** — Predictable behavior and maintainable tools.
- **Iteration** — Refining products through feedback and updates.
